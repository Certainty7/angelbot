# PII sweep — 2026-11-25

Scope: `README*.md`, `docs/**`, `website/public/**`, every image shipped in `docs/screenshots/`, and
the full git history.

## What was checked

- **Snowflake grep** across tracked text:
  `git grep -nIE "\b[0-9]{17,20}\b" -- README.md README.ar.md docs website/src`.
  Hits are the public application id, OAuth permission masks, and public post URLs in
  `docs/GALLERY.md`. No member id, no DM channel id, no guild id.
- **Secret scan** across every blob in history: `python3 scripts/scan_secrets.py` → `no secrets found`.
  The scanner is wired into `.github/workflows/checks.yml`, so a token cannot land unnoticed again.
- **Images reviewed at full size**: `architecture`, `message-pipeline`, `deploy-gate`, `recall-probe`,
  `website/public/og-image.png`. No username, avatar, server name, phone number, plate, email or token
  is visible in any of them.
- **Demo fixtures**: the recall probe (`tools/recall_probe.py`) used to ship a persona-flavoured set of
  facts (a city, a job, a car, a relative's name). They were synthetic, but a reader cannot know that,
  so they are now obviously fictional (`مدينة الشمال`, `مهندس أنظمة`, `أخي الأكبر`) and the probe still
  scores 10/10.
- **Images are generated, not captured by hand**: `tools/design/gen_architecture.py`,
  `gen_pipeline.py`, `gen_terminal_svg.py`, `gen_recall_svg.py` write the SVGs from the module list and
  from real command output, so a future edit cannot silently reintroduce a stale or personal capture.

## Result

Clean. No member data, no infrastructure path, no credential. The only identifiers shipped are the
public Discord application id and public post URLs.
